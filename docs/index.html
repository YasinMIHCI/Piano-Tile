Mes morceaux

Gardés dans ce navigateur : un clic pour rejouer, sans serveur ni nouvelle transcription.

    Transforme un morceau de piano en tutoriel à notes tombantes

    Dépose un enregistrement : un réseau de neurones (basic-pitch, de Spotify) détecte chaque note directement dans ton navigateur, rien n'est envoyé sur un serveur. Les notes tombent ensuite sur un clavier virtuel, synchronisées avec l'audio.

    Nécessite le serveur de transcription (voir Paramètres) : une page statique ne peut pas télécharger depuis YouTube.

    Paramètres
    Détection des notes
    Serveur de transcription (optionnel)

    Le serveur (dossier backend/ du dépôt) ajoute les liens YouTube et un modèle spécialisé piano.

    0:00 / 0:00

    main droite main gauche · Espace : lecture/pause · ← → : ±5 s

    Comment ça marche

    1. Décodage : l'audio est converti en mono 22 kHz par le navigateur (Web Audio).
    2. Transcription : basic-pitch (TensorFlow.js, sur la carte graphique via WebGL) estime pour chaque instant quelles notes commencent et lesquelles résonnent.
    3. Nettoyage : on retire les notes hors tessiture, trop courtes ou fantômes, puis on répartit les mains autour du Do central.
    4. Rendu : un canvas dessine les notes à 60 images/s, calées sur la lecture de l'audio d'origine.

    Limites

    La transcription n'est pas parfaite : les accords denses, la pédale de sustain, la réverbération ou d'autres instruments créent des fausses notes et des erreurs d'octave. Les meilleurs résultats viennent d'enregistrements de piano seul, propres et proches du micro. Joue avec les seuils dans les Paramètres, ou utilise le serveur avec son modèle spécialisé piano, plus précis. La répartition des mains est une approximation.
